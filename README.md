# Rhoomi Vault

A personal static website for recipes, routines, interests, travel plans, skincare references, and useful tips.

## Repository Structure

```text
rhoomi-vault/
|-- index.html
|-- Activities/
|   |-- Indoor/
|   `-- Outdoor/
|-- Interests/
|   |-- architecture.html
|   |-- furniture.html
|   |-- gut-health.html
|   |-- movies-to-watch.html
|   |-- novels.html
|   |-- photography.html
|   `-- series-to-watch.html
|-- Recipes/
|   |-- Beverages/
|   |-- Breakfast/
|   |-- Dessert/
|   |-- Meals/
|   `-- Tips/
|-- Routines/
|   |-- PreViral/
|   `-- Rhoomi/
|-- Skincare/
`-- Travel/
    |-- currency-converter.html
    |-- 2026/
    |   |-- Iceland/
    |   `-- New Mexico/
    |-- Outfits/
    |   |-- index.html
    |   |-- fitcheck.html
    |   `-- wardrobe.html
    `-- Things-To-Carry/
        `-- checklist.html
```

The root `index.html` provides navigation to each active section. Nested `index.html` files provide navigation within Recipes, Travel, Outfits, and Routines.

`Activities/Indoor/` and `Activities/Outdoor/` are reserved for future pages and are not shown in site navigation while empty.
