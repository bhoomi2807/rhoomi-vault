# Rhoomi Vault

A personal static website for recipes, routines, interests, travel plans, skincare references, and useful tips.

## Repository Structure

```text
rhoomi-vault/
|-- index.html
|-- Interests/
|-- Recipes/
|-- Routines/
|   |-- PreViral/
|   `-- Rhoomi/
|-- Skincare/
|-- Tips/
`-- Travel/
    |-- 2026/
    |   |-- Iceland/
    |   `-- New Mexico/
    |-- Outfits/
    |   |-- index.html
    |   |-- fitcheck.html
    |   `-- wardrobe.html
    `-- Things-To-Carry/
        `-- checklist.html
```

The root `index.html` provides navigation to each section. Nested `index.html` files provide navigation within Travel, Outfits, and Routines.
